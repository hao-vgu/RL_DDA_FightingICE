# RL_DDA_FightingICE
The project of implementing reinforcement learning (RL) for dynamic difficulty adjustment (DDA) in fighting game.
  - FightingICE is a game used for DarefightingICE competition, and one of the track is using AI agents to control characters using sound input.
  - Because of the source code project being available on Github, the game was chosen, and many reports use this game for thesis researches.
